# ABC Motor Insurance Demo

ระบบจำลองการเลือกซื้อประกันรถยนต์ของบริษัท ABC (บริษัทสมมติ) ตั้งแต่หน้าลูกค้าไปจนถึงหลังบ้านและ Performance Dashboard
เป็นไฟล์ HTML ไฟล์เดียว เปิดใช้ได้ทันที ไม่ต้องมี server หรือ database

**เปิดเดโม:** ดาวน์โหลด `dist/index.html` แล้วดับเบิลคลิกเปิดในเบราว์เซอร์

**ฉบับ Offline (ไม่ต้องต่ออินเทอร์เน็ตเลย):** ดาวน์โหลด `dist/abc-motor-insurance-demo-offline.zip` แตกไฟล์ แล้วดับเบิลคลิก `abc-motor-insurance-demo.html` ฟอนต์ฝังอยู่ในไฟล์แล้ว รายละเอียดอยู่ใน `README.txt` ในไฟล์ zip

## Multi-Lens BI Dashboard (แดชบอร์ด 4 เลนส์)

แดชบอร์ดภาพรวมธุรกิจประกันวินาศภัยแยกเป็นไฟล์เดียว ออกแบบตาม "The Multi-Lens Blueprint" (Strategic / Operational / Tactical / Analytical) ใช้ข้อมูลจำลองทั้งหมด (GWP ประมาณ ฿5,000 ล้านต่อปี, ม.ค. 68 – ก.ย. 69)

**เปิดใช้:** ดาวน์โหลด `dist/bi-dashboard.html` แล้วดับเบิลคลิก (ฉบับไม่ต้องต่ออินเทอร์เน็ต: `dist/offline/abc-bi-dashboard.html`)

| เลนส์ | คำถามที่ตอบ | เนื้อหา |
|---|---|---|
| 1. ผลประกอบการธุรกิจ (Strategic) | เรายังเดินตามเป้าหมายอยู่หรือไม่ | GWP, NEP, Loss / Expense / Combined Ratio, UW Profit, ROE, Market Share + การเติบโตเทียบตลาด, GWP สะสมเทียบเป้าและปีก่อน, แยกตามสายผลิตภัณฑ์และช่องทาง |
| 2. ผลงานฝ่ายปฏิบัติการ (Operational) | เกิดอะไรขึ้นตอนนี้ และอะไรต้องแก้ด่วน | SLA ของ Underwriting (เสนอราคา, ออกกรมธรรม์, สลักหลัง) และ Claim (รับแจ้ง→ถึงที่เกิดเหตุ, อนุมัติซ่อม/พิจารณาสินไหม, จ่ายค่าสินไหม), สัญญาณไฟแดง/เขียว, วงจรงาน, รายการงานเกิน SLA, ผลงานรายบุคคล + Hit Ratio (อัปเดตทุก 30 วินาที) |
| 3. การตลาดและการขาย (Tactical) | ทีมขายทำได้ตามเป้าไหม | 4 ช่องทาง (Agency, Broker, Banca, Direct/Digital): งานใหม่ vs เป้า, อัตราต่ออายุและเบี้ยต่ออายุ, Renewal SLA (แจ้งล่วงหน้า ≥60 วัน), Lead conversion, Leaderboard 24 หน่วยขาย |
| 4. วิเคราะห์ธุรกิจ (Analytical) | ทำไมจึงเกิดขึ้น | Heatmap Loss Ratio สายผลิตภัณฑ์ × ช่องทาง/ภูมิภาค พร้อมเจาะลึก, ความถี่ × ความรุนแรงเคลม, การกระจายมูลค่าเคลม, การต่ออายุตามการเปลี่ยนเบี้ย/อายุลูกค้า/สาเหตุ, กำไรตามกลุ่ม, ข้อมูลดิบ |

- ตัวกรองรวม: MTD / QTD / YTD, เดือน, สายผลิตภัณฑ์, ช่องทาง, ภูมิภาค (ใช้กับทุกเลนส์)
- คลิก KPI / แท่งกราฟ / ช่อง Heatmap เพื่อเจาะลึกข้ามเลนส์
- ศูนย์แจ้งเตือน (กระดิ่ง) รวม KPI สีแดง/เหลืองและงานเกิน SLA พร้อม Action ที่แนะนำ
- ดาวน์โหลด CSV ทุกตาราง และพิมพ์/บันทึก PDF
- เกณฑ์สี: เขียว ≥95% · เหลือง 85–95% · แดง <85% ของเป้า/SLA (อัตราส่วนที่ยิ่งต่ำยิ่งดีใช้ แผน ÷ ผลจริง)
- สลับ TH / EN และธีมสว่าง/มืด
- โค้ดอยู่ใน `src/bi/` สร้างไฟล์ด้วย `npm run build`

## สิ่งที่ทำได้

| ส่วน | รายละเอียด |
|---|---|
| หน้าลูกค้า | เลือกรหัสรถ (110 รถเก๋ง/รถยนต์นั่ง, 210 รถตู้, 320 รถกระบะ หรืออื่นๆ) → ยี่ห้อ (มีไอคอน) → รุ่น → ปีรถ ระบบกรองยี่ห้อและรุ่นตามรหัสรถ เช่น Camry อยู่ใน 110 ส่วน Hilux Revo อยู่ทั้ง 110 และ 320 แล้วแนะนำทุนประกันตามมูลค่ารถปัจจุบัน |
| Self service | ชั้น 2+, 3+ และ พ.ร.บ. ซื้อเองได้ทันที: แนบเอกสาร → เลือกรับกรมธรรม์ (กระดาษส่ง EMS หรือ e-Policy PDF ทางอีเมล) → ชำระเงินจำลอง (QR พร้อมเพย์หรือบัตร) → ออกกรมธรรม์อัตโนมัติ |
| ช่วยลูกค้าเลือก | ป้าย "ขายดีที่สุด" / "คุ้มที่สุด", บอกความคุ้มครองเป็นสถานการณ์ (ชนมีคู่กรณี, ชนเอง, รถหาย/ไฟไหม้, น้ำท่วม, ชดใช้คนอื่น), เปรียบเทียบได้สูงสุด 3 แพ็กเกจแบบตาราง |
| ผ่อน 0% | การ์ดแสดงราคาต่อเดือน (10 เดือนเมื่อเบี้ย ≥ ฿10,000, 6 เดือนเมื่อ ≥ ฿4,000) และเลือกผ่อนได้ตอนจ่ายด้วยบัตรใน Self service |
| ส่งราคาให้ฉัน | ลูกค้าที่ยังไม่พร้อมซื้อทิ้งเบอร์/อีเมลไว้ ระบบส่งราคา (จำลอง) แจ้งเตือนหลังบ้าน แสดงในแท็บ "ผู้สนใจ (Leads)" และนับว่ากลายเป็นคำขอเมื่อลูกค้าคนเดิมส่งคำขอ |
| ถ่ายบัตรแทนพิมพ์ | ในฟอร์มอัปโหลดรูปบัตรประชาชนหรือเล่มรถ ระบบ "อ่าน" แล้วกรอกฟอร์มให้ (จำลองด้วยข้อมูลตัวอย่าง) และแนบเป็นเอกสารให้อัตโนมัติ |
| ถ่ายรูปรถด้วยมือถือ | ช่องรูปรถแสดงภาพนำทางแต่ละมุม และมีปุ่ม "ถ่ายด้วยมือถือ" (QR + จำลองกล้องมือถือพร้อมกรอบเล็ง) รูปขึ้นที่หน้าคอมอัตโนมัติ |
| ขอเสนอราคา | บอกเวลาที่จะได้ราคาแบบระบุเวลา (เช่น "ภายใน 14:30 น. วันนี้") และให้เลือกช่วงเวลาให้โทรกลับ หลังบ้านเห็นช่วงเวลานั้น |
| หลังได้กรมธรรม์ | บัตรประกันดิจิทัล, ปุ่มแจ้งเคลม (แจ้งหลังบ้านทันที), ตั้งเตือนต่ออายุ 60/30/7 วันและต่อภาษี พร้อมตัวอย่างอีเมล, โค้ดชวนเพื่อน |
| Funnel | เริ่มนับตั้งแต่เข้าชมหน้าเว็บ → เลือกรถครบ → ดูแพ็กเกจ → เลือกแพ็กเกจ/ขอราคา → แจ้งงาน → … |
| ความน่าเชื่อถือ | แถบจุดเด่นบนหน้าแรก (ตัวเลขตัวอย่าง) และปุ่ม "คุยกับเจ้าหน้าที่" |
| ติดตามคำขอ | ค้นหาด้วยเลขที่คำขอ หรือเลขทะเบียนรถ (ไม่สนช่องว่างและขีด) |
| แพ็กเกจ | ชั้น 1 (ซ่อมห้าง/ซ่อมอู่, ค่าเสียหายส่วนแรก), 2+, 3+, 2, 3 และ พ.ร.บ. ซื้อพ.ร.บ.พ่วงได้ เบี้ยและราคา พ.ร.บ. ขึ้นกับรหัสรถ (110 ฿645.21, 210 ฿1,182.35, 320 ฿967.28) |
| ขอเสนอราคา | ใช้เมื่อรุ่นนั้นไม่มีแพ็กเกจ (เช่น Mazda MX-5, Ford Ranger Raptor, BYD Seal), เมื่อลูกค้ากด "ขอเสนอราคา" เอง, หรือรถ/รหัสรถไม่อยู่ในรายการ (กรอกเอง) |
| กรอกข้อมูล | มีค่าตัวอย่างกรอกไว้ให้ ตรวจรูปแบบเลขบัตรประชาชน เบอร์มือถือ และอีเมล |
| แนบเอกสาร | แนบภายหลังจากหน้า "ติดตามคำขอ" ชั้น 1 ต้องมีรูปรถ 4 ด้าน + สำเนาเล่มรถ + สำเนาบัตร ส่วนชั้น 2+, 3+, 2, 3 และ พ.ร.บ. ต้องมีสำเนาเล่มรถ + สำเนาบัตร รับเฉพาะ .jpg ไม่เกิน 3MB ต่อรูป |
| หลังบ้าน | งานเข้าแบบเรียลไทม์ (กระดิ่ง + toast), รับเรื่อง, มอบหมายงาน, ส่งใบเสนอราคา, ตรวจเอกสาร, ขอเอกสารใหม่, ออกกรมธรรม์, ยกเลิก, บันทึกโน้ต |
| อีเมล | อีเมลจำลองถึงลูกค้าและทีมหลังบ้านทุกขั้นตอน (ดูได้ที่เมนู "อีเมลจำลอง") |
| Dashboard | Production (จำนวนกรมธรรม์ / เบี้ยรวม แยกตามวัน เดือน ประเภท ยี่ห้อ เจ้าหน้าที่), Process Funnel, SLA |
| ภาษา | สลับ TH / EN ได้ทุกหน้า |

### สถานะงาน
`ใหม่ → รับเรื่อง → เสนอราคาแล้ว → (ลูกค้ายืนยัน) → รอเอกสาร → ตรวจเอกสาร → ออกกรมธรรม์` หรือ `ยกเลิก`
งานซื้อเอง (Self service): `รอชำระเงิน → ออกกรมธรรม์` ไม่นับ SLA เพราะไม่ต้องรอเจ้าหน้าที่
งานที่มาจากการเลือกแพ็กเกจมีราคาและการยืนยันตั้งแต่ตอนแจ้งงาน จึงข้ามขั้นเสนอราคาไป

### SLA (นับเฉพาะเวลาทำการ จันทร์–ศุกร์ 08:30–17:30 ไม่หักวันหยุดนักขัตฤกษ์)
| SLA | เริ่มนับ | หยุดนับ | เป้าหมาย |
|---|---|---|---|
| รับเรื่อง | ลูกค้าส่งคำขอ | เจ้าหน้าที่รับเรื่อง | 15 นาที |
| เสนอราคา | ลูกค้าส่งคำขอเสนอราคา | ส่งใบเสนอราคา | 2 ชั่วโมง |
| ออกกรมธรรม์ | เอกสารครบ | ออกกรมธรรม์ | 1 วันทำการ |

เมื่องานค้างเกิน SLA ระบบจะแจ้งเตือนในหลังบ้านและส่งอีเมลถึงทีมหนึ่งครั้ง

## วิธีเดโมแบบเรียลไทม์
- เปิดเดโมไว้ 2 แท็บ แท็บแรกเป็น "หน้าลูกค้า" อีกแท็บเป็น "หลังบ้าน" เมื่อลูกค้าส่งคำขอ หลังบ้านจะแจ้งเตือนทันที
- หรือใช้เมนู **แบ่งจอ** เพื่อดูทั้งสองฝั่งในหน้าเดียว

## ข้อจำกัดของเดโม
- ข้อมูลเก็บใน localStorage / IndexedDB ของเบราว์เซอร์ที่เปิดเท่านั้น ไม่ได้แชร์ข้ามเครื่อง
- อีเมลไม่ได้ส่งออกไปจริง
- เมื่อเปิดครั้งแรก ระบบสร้างข้อมูลย้อนหลัง 3 เดือน (ประมาณ 340 งาน) และสร้างใหม่ได้ด้วยปุ่ม "รีเซ็ตข้อมูลเดโม"
- รถ ราคา และเบี้ยประกันเป็นตัวอย่างทั้งหมด ไม่ใช่อัตราจริง
- โลโก้ยี่ห้อ Toyota, Honda, Mazda, Nissan, Mitsubishi, Ford, MG, Suzuki, Hyundai มาจาก [Simple Icons](https://simpleicons.org) (ข้อมูล CC0) ใช้เพื่อระบุยี่ห้อรถของลูกค้าเท่านั้น โลโก้เป็นเครื่องหมายการค้าของเจ้าของแต่ละราย ก่อนใช้กับระบบจริงต่อสาธารณะควรให้ฝ่ายกฎหมาย/แบรนด์ตรวจ ส่วน Isuzu และ BYD ยังเป็นตัวอักษรย่อที่ออกแบบขึ้นเอง
- การชำระเงินและเลขพัสดุ EMS เป็นการจำลอง ไม่มีการตัดเงินหรือจัดส่งจริง

## สำหรับนักพัฒนา
```bash
npm install
npm run typecheck
npm run build                                    # สร้าง dist/index.html และ dist/offline/
npm run package:offline                          # สร้าง dist/abc-motor-insurance-demo-offline.zip
CHROMIUM_PATH=/path/to/chromium npm run test:offline  # เปิดไฟล์ offline โดยบล็อกเน็ตทั้งหมดแล้วตรวจ
CHROMIUM_PATH=/path/to/chromium npm test         # ทดสอบ end-to-end ด้วย Playwright
```

โครงสร้างโค้ด (React + TypeScript, bundle ด้วย esbuild)
```
src/data/      ข้อมูลรถ ทุนประกัน แพ็กเกจ และเอกสารที่ต้องใช้
src/lib/       เวลาทำการ, การคำนวณ SLA, ตัวสร้างข้อมูลย้อนหลัง
src/store.ts   state และ action ทั้งหมด (ส่งคำขอ, รับเรื่อง, เสนอราคา, ออกกรมธรรม์ …)
src/files.ts   เก็บรูปที่แนบใน IndexedDB
src/ui/        หน้าลูกค้า, หลังบ้าน, Dashboard, อีเมลจำลอง
```
ถ้าจะต่อยอดไปใช้จริง ให้เปลี่ยน action ใน `src/store.ts` และ `src/files.ts` ให้เรียก API จริง โดยไม่ต้องแก้หน้าจอ
