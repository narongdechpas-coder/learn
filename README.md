## AI Agent Catalog

`ai-agent-catalog/index.html` — หน้า Interactive อธิบาย AI Agent ทั้ง 12 ตัว (9 Reusable + 3 Specialist) สำหรับนำเสนอผู้บริหาร

- การ์ด Agent แต่ละตัว → ปัญหาเดิม, AI ทำอะไร, ก่อน/หลังใช้ AI, Benefit ต่อธุรกิจ และโครงการที่ใช้
- Reuse Map: เลือกโครงการเพื่อดูว่าประกอบจาก Agent ตัวไหนบ้าง
- ROI Simulator: ปรับสมมติฐานเพื่อประเมินความคุ้มค่าต่อปี (ค่าประมาณ)
- ลิงก์ตรงไปยัง Agent ได้ด้วย `#agent-01` … `#agent-12`

เปิดไฟล์ด้วยเบราว์เซอร์ได้ทันที ไม่ต้อง build
