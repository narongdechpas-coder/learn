Solution architecture

ระบบเชื่อมกันอย่างไร

CRM ทำหน้าที่ทำงานกับเคส (Ticket, SLA, Routing) ส่วน CDP เป็นศูนย์รวมตัวตนลูกค้า (Identity) และคำแนะนำ (NBA) โดยดึงข้อมูลกรมธรรม์และเคลมจาก Core System

Real-time API (< 300 ms) Event stream (เขียนกลับเข้า CDP) Batch / Sync รายวัน

ลำดับข้อมูลเมื่อมีสายเข้า

  1. สาย / แชทเข้าCTI ได้เบอร์โทร (ANI), LINE ได้ UID, Facebook ได้ PSID แล้วส่งเข้าคิวตาม IVR หรือ Keyword
  2. Identity ResolutionCRM ส่ง Identifier ให้ CDP จับคู่แบบ Deterministic (เบอร์, LINE UID, เลขบัตร) หรือ Probabilistic (Cookie, Device)
  3. Screen PopCDP คืน Profile 360, กรมธรรม์, เคลม, Journey, Sentiment และ NBA แล้วแสดงเป็น Pop-up ก่อน Agent กดรับ
  4. เปิด TicketAgent เลือกหมวด CRM คำนวณ SLA และ Assign ทีม ระบบ AI ช่วยสรุปบทสนทนา
  5. Wrap-upบันทึกผล Disposition, Consent (PDPA) และผลตอบรับ NBA
  6. เขียนกลับเข้า CDPส่ง Event, อัปเดต Segment และสั่ง Journey ต่อ เช่น LINE แจ้งสถานะ หรือแบบสำรวจ CSAT
