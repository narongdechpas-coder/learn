# ABI Mobile App — เช็คเบี้ยประกันรถยนต์ (ต้นแบบ)

หน้าแอปตามดีไซน์ ABI Mobile App + ระบบที่ใช้งานได้จริง:
เช็คเบี้ย → ชำระเงิน → รับกรมธรรม์ PDF

> ⚠️ ต้นแบบเพื่อการทดลอง อัตราเบี้ยเป็นตัวอย่าง และการชำระเงินเป็นแบบจำลอง (mock) ไม่มีการตัดเงินจริง

## เริ่มใช้งาน

```bash
cd car-insurance
npm install
npm start          # build หน้าแอปแล้วเปิด http://localhost:3000
npm test           # รันชุดทดสอบ
```

### ไม่สะดวกติดตั้ง Node.js? ใช้ไฟล์เดียวแบบ offline

`npm run build:offline` จะได้ `dist/abi-offline.html` (~3 MB) ดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย
ใช้โค้ดคำนวณเบี้ย/ชำระเงิน/สร้าง PDF ชุดเดียวกับเซิร์ฟเวอร์ แต่ข้อมูลอยู่ในหน่วยความจำ ปิดหน้าแล้วหาย

ตัวแปรแวดล้อม: `PORT` (ค่าเริ่มต้น 3000), `DATA_FILE` (ค่าเริ่มต้น `data/db.json`),
`ENABLE_MOCK_GATEWAY=false` เพื่อปิด endpoint ของ gateway จำลอง

## ขั้นตอนซื้อประกัน (หน้าหลัก → เช็คเบี้ย)

1. **ข้อมูลรถ** — Dropdown ยี่ห้อ → รุ่น → ปี (พ.ศ.)
   - รุ่นเปลี่ยนตามยี่ห้อ, ประเภทตัวถังและทุนประกันตั้งต้นตามรุ่น (แก้ทุนประกันได้)
   - **ปีรถเลือกได้ไม่เก่ากว่าปีที่รุ่นนั้นเริ่มขายในไทย** เช่น Toyota bZ4X เลือกได้แค่ 2568–2569 (ย้อนหลังสูงสุด 14 ปี)
2. **ระดับความคุ้มครอง** — ชั้น 1 / 2+ / 3+ / 3 พร้อมราคาประเมิน
3. **ปรับแต่งแผน** — ซ่อมอู่/ห้าง, อายุผู้ขับขี่, ความคุ้มครองเสริม (PHYD −12%, น้ำท่วม, อุบัติเหตุผู้ขับขี่, ช่วยเหลือฉุกเฉิน), พ.ร.บ.
4. **สรุปเบี้ย** → ซื้อเลย (เซิร์ฟเวอร์คำนวณราคาใหม่และล็อกราคา 30 นาที)
5. **ชำระเงิน** — ข้อมูลผู้เอาประกัน/รถ/วันเริ่มคุ้มครอง, จ่ายเต็ม หรือผ่อน 0% 10 เดือน (บัตรเท่านั้น), บัตร หรือพร้อมเพย์ QR
   - บัตรทดสอบ `4242 4242 4242 4242` = สำเร็จ, `4000 0000 0000 0002` = ถูกปฏิเสธ
   - พร้อมเพย์: กด "(ทดสอบ) จำลองว่าสแกนจ่ายแล้ว"
6. **สำเร็จ** — ดาวน์โหลดกรมธรรม์ PDF และกรมธรรม์ใหม่จะเข้าไปอยู่ใน "กรมธรรม์ของฉัน"

ส่วนอื่นของแอป (แจ้งเคลม, ต่ออายุ, PHYD, การแจ้งเตือน, บัญชี) ยังเป็นข้อมูลจำลองตามดีไซน์เดิม

## โครงสร้าง

```
app/                 ซอร์สหน้าแอป (React + design system ของดีไซน์)
  vendor/            lucide, Aioi design system bundle
  styles/ assets/    โทเคน CSS, ฟอนต์ Kanit/Sarabun/IBM Plex Mono, รูปรถ
  quote.jsx          วิซาร์ดเช็คเบี้ย
  purchase.jsx       หน้าชำระเงินที่เชื่อม API จริง (checkout.jsx = ต่ออายุแบบจำลองเดิม)
  api.js             เรียก API ของระบบ
scripts/build.js     สร้าง public/ (ให้เซิร์ฟเวอร์) หรือ dist/abi-offline.html (--offline)
src/
  catalog.js         ยี่ห้อ/รุ่น: ประเภทตัวถัง, ราคาตั้งต้น, ปีที่เริ่มขายในไทย
  premium.js         สูตรเบี้ยตามดีไซน์ (ใช้ร่วมกันทั้งเซิร์ฟเวอร์และหน้าแอป)
  service.js         ตรรกะหลัก: เช็คเบี้ย/สั่งซื้อ/ชำระเงิน
  payment.js         payment gateway จำลอง (tokenize บัตร, charge, Thai QR + CRC16)
  policyPdf.js       สร้าง PDF กรมธรรม์ (pdfkit + Sarabun)
  server.js          Express API
demo/                แบ็กเอนด์จำลองในเบราว์เซอร์สำหรับไฟล์ offline
test/                unit test + ทดสอบ flow ครบวงจรผ่าน API
```

## API

| Method | Path | คำอธิบาย |
|---|---|---|
| GET | `/api/options` | แคตตาล็อกรถ (พร้อมปีที่เลือกได้), ผลิตภัณฑ์, ความคุ้มครองเสริม |
| POST | `/api/quotes` | `{ brand, model, year, sumInsured, coverageClass, repair, driverAge, addons, withCmi }` → ราคา (ล็อก 30 นาที) |
| POST | `/api/orders` | `{ quoteId, holder, vehicle, startDate, paymentPlan }` → `id`, `accessToken` |
| GET | `/api/orders/:id` | สถานะคำสั่งซื้อ (header `x-order-token`) |
| POST | `/api/orders/:id/pay` | `{ method: "card", cardToken }` หรือ `{ method: "promptpay" }` |
| GET | `/api/orders/:id/policy.pdf?token=…` | ดาวน์โหลดกรมธรรม์ (เฉพาะที่ชำระแล้ว) |

## หลักความปลอดภัยที่ใช้

- **ราคาคิดฝั่งเซิร์ฟเวอร์เสมอ** — หน้าแอปคำนวณไว้แสดงผลเท่านั้น ตอนซื้อเซิร์ฟเวอร์คำนวณใหม่และล็อกราคา
- **เลขบัตรไม่ผ่านเซิร์ฟเวอร์เรา** — tokenize กับ gateway ก่อน แล้วส่งแค่ token (ใช้ได้ครั้งเดียว)
- **ออกกรมธรรม์แบบ idempotent** — ตรวจยอดเงินตรงกับคำสั่งซื้อ และไม่ออกซ้ำ
- **ป้องกันการเดา URL** — ดูคำสั่งซื้อ/PDF ต้องมี access token แบบสุ่ม

## ก่อนนำไปใช้จริง

- ตรวจสอบราคาตั้งต้นและปีที่เริ่มขายใน `src/catalog.js` และอัตราเบี้ยใน `src/premium.js` กับข้อมูลจริง
- ใส่ไฟล์โลโก้ที่ `app/assets/aioi-mark.png` (ตอนนี้แสดงเป็นตัวอักษรแทน) และตั้งชื่อบริษัทใน `src/policyPdf.js`
- เปลี่ยน `src/payment.js` เป็น gateway จริง และรับผลผ่าน webhook ที่ตรวจลายเซ็น
- เปลี่ยน `src/store.js` เป็นฐานข้อมูลจริง และเพิ่มระบบสมาชิก/ล็อกอิน
