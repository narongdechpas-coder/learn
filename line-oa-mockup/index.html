ลำดับการใช้งานแต่ละบริการ

A · LIFF

เช็คเบี้ยประกัน

  1. เปิด LIFF ฟอร์ม ระบบเติมรหัสคู่ค้าให้อัตโนมัติ
  2. เลือกประเภทประกัน ยี่ห้อ รุ่น (รายการตามยี่ห้อ) ปี และทุน ช่องซ่อมห้าง/อู่แสดงเฉพาะชั้น 1
  3. การ์ดแรกเป็นชั้นที่เลือก ตามด้วยชั้นใกล้เคียงให้เทียบ
  4. ปุ่ม “ออกใบเสนอราคา” ส่ง PDF ให้ลูกค้าต่อได้ทันที
B · postback

งานครบกำหนดต่ออายุ

  1. สรุปจำนวนงาน ต.ค. 69 และ พ.ย. 69
  2. Carousel เรียงตามวันหมดอายุ ใกล้สุดก่อน
  3. สถานะ: ยังไม่เสนอ / เสนอแล้ว / ลูกค้าตอบรับ
  4. ส่งรายการทั้งหมดเป็น Excel ทางอีเมล
C · postback + ข้อความ

ขอสำเนากรมธรรม์

  1. บอทขอคำค้น หรือเลือกจาก Quick Reply งานล่าสุด
  2. แสดงการ์ดกรมธรรม์ (ค้นได้เฉพาะลูกค้าของคู่ค้ารายนั้น)
  3. ส่ง PDF ในแชท หรือส่งอีเมลลูกค้าที่อยู่ในระบบ
D · postback

สถานะรับชำระ / Credit Limit

  1. แถบวงเงิน: บิลรอชำระ + งานยังไม่วางบิล + คงเหลือ
  2. รายการบิลพร้อมวันครบกำหนดและสถานะ
  3. เตือนเมื่อใช้วงเงินเกิน 80% หรือบิลเกินกำหนด

ข้อควรรู้ก่อนพัฒนา

  • ภาพ Rich Menu เป็นภาพนิ่ง ตัวเลขอย่างจำนวนงานต่ออายุจึงไม่ควรใส่บนปุ่ม ให้ส่งเป็น push message ต้นเดือนแทน (ตัวอย่างข้อความแรกในแชท)
  • ใช้ Rich Menu 2 ชุด: partner-pre เป็นค่าเริ่มต้นของ OA และ partner-main ผูกรายบุคคลด้วย POST /v2/bot/user/{userId}/richmenu หลังยืนยันตัวตนสำเร็จ
  • ข้อมูลกรมธรรม์และการเงินเป็นข้อมูลส่วนบุคคล ต้องผูก LINE userId กับรหัสคู่ค้าก่อน และตรวจสิทธิ์ทุกคำขอว่าเป็นลูกค้าของคู่ค้ารายนั้น
  • ไฟล์ภาพ JPEG หรือ PNG ไม่เกิน 1 MB ข้อความบนปุ่มควรสูงอย่างน้อย 60 px ในภาพจริงเพื่อให้อ่านได้บนมือถือ
  • chatBarText ยาวได้ไม่เกิน 14 ตัวอักษร ใช้ “เมนูคู่ค้า”
